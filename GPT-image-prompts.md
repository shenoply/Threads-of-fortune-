# Threads of Fortune: image prompts for ChatGPT

## How to use
1. Start one new ChatGPT chat and paste the **STYLE LOCK** first. Keeping everything in one chat keeps the look consistent.
2. Then paste one prompt at a time: **one image per message**.
3. Download each image and send it back here with the file name shown in each heading (e.g. `yusuf-stall.png`). I'll crop, colour-match and put it in the game.
4. If an image comes out too clean or modern, reply to ChatGPT with: *"More painterly, warmer, visible brush strokes, like the reference, less digital."*

It helps a lot if you also attach your original Samira stall picture to the first message as the style reference.
