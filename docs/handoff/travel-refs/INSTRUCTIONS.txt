THREADS OF FORTUNE: TRAVEL ART BATCH (7 images)

How to use:
1. Open ChatGPT (image generation).
2. For each prompt below, start the message by attaching the reference images it names
   (links at the bottom of this file), then paste the prompt text.
3. One image per message. Do #7 last, in the SAME chat as #6, attaching #6's result.
4. Save each result named as shown (01-camel-cut.png and so on). If the background comes out
   white or checkered instead of transparent, keep it anyway; it will be cut out later.
5. Zip the 7 results and send them back (under about 14 MB, or split into Part 1 and Part 2).

Shared style (already included in the prompts): hand-painted, semi-realistic, warm ochre,
umber and faded madder red, soft light from the upper left, no text, no border.
