THREADS OF FORTUNE: STALL WEATHER AND TIME-OF-DAY BATCH (6 images)

The stall at Giza is shown behind every customer. Today it is always the same sunny midday.
These six versions let it change with the hour and the weather. The game swaps them by the clock
and the day's weather, so every version MUST keep the exact same layout as the base picture:
the shelves, the little brass table, the red pouf, the hanging rugs on the left, the posts, the
awning and the red counter cloth must not move by a single pixel. Only light, sky and weather change.

How to use:
1. Open ChatGPT (image generation). Start a new chat for each image.
2. Attach ref-S-stall-base.png (link at the bottom), paste the prompt, send.
3. Save each result under the name shown (S1-dawn.png and so on).
4. If the layout moves (shelves shifted, table redrawn elsewhere), ask ChatGPT:
   "Keep everything in the exact same place as the attached image; only change the light."
5. Send the six back as a zip or put them in the Drive folder.

Shared rules (already in every prompt): same camera, same framing, same objects in the same place,
no people inside the stall, no text, no border, landscape 1536x1024, painted in the same warm
semi-realistic style as the attached picture.
