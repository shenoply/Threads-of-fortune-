# Retired browser scripts

These early screenshot and playthrough scripts read a prepared save from `/home/claude/shots/save.json`,
a path from the environment they were written in. That file is not in the repository and nothing here
creates it, so they cannot run anywhere now. They are kept for reference (each shows how a screen used
to be driven); the maintained tests are in `tests/` and run with `PORT=5173 node tests/<name>.mjs`.
